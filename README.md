# Продуктовая ферма

Автономный путь: идея текстом или голосом → исследование → варианты и прогоны → расчёт → независимая критика → отчёт → решение человека → декларативный MVP.

Текущий стек по отчёту v1.3: Next.js / React / TypeScript, Vercel Workflow, Neon PostgreSQL, Private Blob, RouterAI (LLM, STT, Web Search + Exa), Python Function с NumPy/SciPy и отдельно вызываемый HTTP-компонент Rules. Всё приложение публикуется в одном проекте Vercel, без внешнего backend и Cloudflare Tunnel.

Приложение находится в `web`; Root Directory в Vercel — `web`, Output Directory без переопределения. Имена серверных переменных: [web/.env.example](web/.env.example). Локальные ключи и `.env.local` не публикуются в Git.

RouterAI оплачивается по использованию. Версионный предел исследования — **20 ₽**. Фактическая стоимость и неподтверждённые резервы отображаются в интерфейсе; предел прекращает новые запросы, но не задаёт тариф провайдера для уже отправленного запроса. Голосовой ввод и MVP учитываются отдельно.

Исторические данные не переносятся и не удаляются. Ненужные исходники прежнего Docker/backend-контура удалены из текущего дерева; они остаются в истории Git. По указанию пользователя тесты и пробные ИИ-запросы не запускаются. Сборка Vercel является частью публикации, а не подтверждением сквозного сценария.
