# Продуктовая ферма

Приложение для автономной проверки продуктовых идей: текст/голос → исследование и источники → варианты и прогоны → расчёт → критическая оценка → решение человека → MVP одного сценария.

**[Полная документация](docs/README.md)** · [Руководство пользователя](docs/user-guide.md) · [Архитектура](docs/architecture.md) · [API](docs/api.md) · [Развёртывание](docs/serverless-deployment.md) · [Статус проверки](docs/verification.md)

Текущий контур: Next.js/React/TypeScript и Vercel Workflow в одном Vercel-проекте, Neon PostgreSQL, Private Blob, RouterAI с Qwen, отдельным критиком, Whisper и поиском Exa; Python Function считает эффект, HTTP Rules проверяет структурированный результат. Исходники приложения находятся в `web`. Исторический Docker/backend-контур удалён из рабочего дерева, но остаётся в истории Git; перенос прежних данных отменён пользователем.

Локальная подготовка: создайте `web/.env.local` по [списку переменных](web/.env.example), установите зависимости по lockfile и примените миграции из `web/drizzle`. Vercel: Root Directory `web`, Node 22.x, Output Directory без переопределения. Команды и ограничения описаны в [инструкции развёртывания](docs/serverless-deployment.md). Секреты не сохраняются в Git.

Предел **20 ₽** относится к старту новых платных вызовов одного исследования с учётом резервов; итоговая стоимость уже отправленного запроса зависит от RouterAI. STT и MVP учитываются отдельно. Действующая политика задаёт максимум **6 поисковых вызовов**, два варианта и три повторения на задачу. Число можно проверить в `web/farm/policy.json` и изменить только через новую версию политики. [Методика](docs/calculation.md) объясняет, почему машинный тайминг не равен подтверждённой экономии.

Документация отражает текущие исходники и их известные ограничения. В рамках последнего обновления документации тесты приложения и платные модельные вызовы не запускались; опубликованная ранее сборка не подтверждает выполнение последующих коммитов. [План проверки](docs/verification.md) отделяет анализ кода от реального прогона.
