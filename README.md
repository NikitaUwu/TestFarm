# Продуктовая ферма

Автономная проверка идеи: текст или голос → исследование рынка → варианты → прогоны → расчёт → критический отчёт → решение → декларативный MVP.

Текущий целевой стек по отчёту v1.2: один проект Vercel, Next.js Route Handlers, Vercel Workflow, Neon PostgreSQL, Private Blob, Царь Роутер, Tavily, Python Function и HTTP-компонент Rules.

- [Настройка и развёртывание](docs/serverless-deployment.md)
- [Состояние переноса и ограничения](docs/serverless-progress.md)
- [Исходный отчёт v1.2](docs/target-report-v1.2.md)
- [Постоянные инструкции](AGENTS.md)

Исходники приложения находятся в `web`. Root Directory проекта Vercel — `web`; Output Directory оставьте без переопределения. Секреты задаются серверными переменными, примеры имён — `web/.env.example`.

После установки зависимостей из `web` миграции схемы применяются командой `npx --yes pnpm@10.34.5 run db:migrate`. По указанию пользователя новый контур запускается без переноса старых аккаунтов и результатов. Пользователи самостоятельно регистрируются заново.

Каталоги `backend`, `runner`, конфигурация Docker Compose и прежние отчёты сохранены как исторический контур. Они не входят в целевое развёртывание и не нужны для запуска. Старые volumes и файлы не изменяются.

По текущему указанию пользователя тесты и контрольные прогоны приостановлены. Готовность исходников не означает подтверждённую работоспособность облачного deployment.
