# Проверка и текущий статус

Дата: 22 сентября 2026. Эта страница — точка входа для приёмки текущего serverless-контура. Старые результаты Docker/Groq относятся к удалённому runtime и не подтверждают RouterAI/Vercel. Действующая задача — документация и GitHub; приложение, база, внешние модели и пользовательские сценарии в её рамках **не тестировались**.

## Что можно установить без запуска приложения

| Наблюдение по исходникам | Основание | Ограничение вывода |
| --- | --- | --- |
| API объединён в Next.js Route Handler; расчёт — Python Function | `web/app/api/[...path]/route.ts`, `web/api/calculate.py` | Не доказывает доступность runtime |
| Очередь использует Neon и Vercel Workflow | `dispatcher.ts`, `workflow.ts` | Не доказывает корректность восстановления под нагрузкой |
| RouterAI выбран единым AI-шлюзом | `providers.ts`, `policy.json` | Не доказывает доступность моделей или состояние баланса |
| Источники — citations без чтения страниц | `citations.ts`, `workflow-steps.ts` | Не гарантирует полноту/верность фрагмента |
| Условия измеренного эффекта строже, чем машинный тайминг | `api/calculate.py` | В текущих синтетических прогонах эффект обычно null |
| Пилотный UI хранит данные локально | `PostMvpMonitoring.tsx` | Не является серверным наблюдением или пересчётом |
| Публичный API возвращает `report.content` | `api.ts` | Может включать исходный текст идеи; нужна оценка перед публикацией |

Предыдущая публикация v1.3 достигла Vercel `READY` (см. [запись релиза](release-v1.3.md) и журнал), но готовность сборки не равна сквозной проверке исследования. Более поздние коммиты и эта документация не заявляются как вновь развернутые или проверенные на продакшене.

## Короткий план контрольной приёмки

План предназначен для отдельного разрешённого прогона с бюджетом RouterAI, собственной тестовой идеей и аккаунтом. В текущем запросе он не выполняется.

1. Развернуть в отдельном окружении с Neon/Private Blob и серверными переменными. Создать два аккаунта; проверить, что второй не читает чужие ID, а публичная ссылка открывает только отчёт и отзывается.
2. Ввести идею текстом, затем отдельную короткую русскую запись. Проверить сохранённый transcript, исправление текста, отказ микрофона и ошибку STT. Сравнить подтверждённый `usage.cost` с резервами.
3. Запустить исследование, закрыть вкладку и вернуться. Проверить queue → Workflow → checkpoints, выбор модели critic, ссылки источников, отсутствие выдуманных дат, пределы 6 поисков/20 ₽, объяснение пробелов. Проверить паузу, retry и неизменность успешных шагов.
4. Сравнить два варианта на одном dataset, проверить сырые попытки, Python CalculationRun и null для отсутствующего измеренного baseline; отдельно на заранее измеренном наборе проверить paired bootstrap и формулу.
5. Принять решение с критериями, создать MVP, отправить новый ввод дважды с одинаковым ключом, проверить сохранённый результат и Rules. Удалить тестовую идею и проверить активные Blob/Neon; отдельно оценить осиротевшее аудио и localStorage.

После такого контрольного прогона записать краткий отчёт «сделано / осталось». До него статус RouterAI STT, русского structured JSON, очереди под сбоями, полного удаления и доступности интерфейса остаётся **не подтверждён**.
