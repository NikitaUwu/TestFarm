## Нефункциональная приёмка

Persistence: перезапуск контейнеров сохраняет карточку/артефакт/run; authorization: чужие UUID возвращают 404; privacy: ключ отсутствует в UI/log/report; accessibility: keyboard/focus/390px; background jobs: закрытие вкладки не влияет на run; correctness: контрольные численные тесты; observability: ошибки и измерения видны в run; maintainability: смена промпта не требует UI-кода. Для performance пока заданы только таймауты BudgetPolicy, SLA задержки интерфейса не заявляется без измерений.
