# Требования и карта покрытия

Текущий реестр для serverless-контура по состоянию на 22 сентября 2026 года. Архивный реестр от 9 сентября сохранён в [истории Git](https://github.com/NikitaUwu/TestFarm/blob/45f9da7/docs/requirements.md); его ID не переназначаются. Источник текущих ограничений — [AGENTS.md](../AGENTS.md), [отчёт v1.3](target-report-v1.3.md) и более поздние указания пользователя. `P0` означает обязательное для заявленного сценария, `P1` — важное дополнение. Статус «код» означает наличие пути в исходниках, а не пройденный end-to-end прогон. Актуальная проверка: [verification.md](verification.md).

## Изменения к первоначальному плану

- Вместо выбора ролей — самостоятельная регистрация личных аккаунтов.
- Вместо FastAPI/Worker/Runner/MinIO — один Vercel-проект с Neon, Workflow, Python Function и Private Blob.
- Вместо бесплатного Groq/Царь Роутера/Tavily — RouterAI pay-as-you-go; основной Qwen, отдельный критик, Whisper и Exa.
- Перенос прежних аккаунтов и данных отменён владельцем проекта. Исторические хранилища не очищаются.
- В отчёте v1.3 поиск допускает до 8 вызовов; действующая policy задаёт максимум 6. Это фактическое сужение объёма, а не свойство RouterAI.
- Текущий API позволяет `develop` вопреки неположительной рекомендации и пишет `override`; это отклонение от исходного перехода A6 и требует отдельного продуктового решения, если нужно закрыть путь.

## Нефункциональная приёмка

| Область | Проверяемый критерий | Состояние сейчас |
| --- | --- | --- |
| Изоляция | Чужой Idea/Run/Report/MVP ID не раскрывает данные | Проверки в коде; нужен отдельный авторизованный сценарий |
| Сохранность | Перезапуск Workflow сохраняет успешные Step/Trial без дублирования | Checkpoints/unique keys в коде; новый restore drill не проводился |
| Бюджет | Новый запрос не стартует при `actual + reserved + estimate > 20 ₽` | Транзакционный код; тарификация отправленного запроса внешняя |
| Доказательность | Факт имеет sourceId и точный quote из snippet | Проверка строки в коде; смысловая сила требует человеческой оценки |
| Расчёт | Измеренный эффект только при полных MEASURED парах | Условие в Python; нужны реальные наблюдения |
| Доступность | Основные операции с клавиатуры и без горизонтальной прокрутки на 390 px | Не проверено |
| Удаление | Удалены все данные идеи, включая непривязанное аудио и клиентские наблюдения | Не достигнуто; см. [политику данных](data-policy.md) |
| Мониторинг | Новое наблюдение создаёт новый CalculationRun и отчёт | Не достигнуто; текущий экран локален |

Ни один пункт таблицы не объявляет пройденный тест. Для достижения A4/§48 остаются реальные измерения, серверный мониторинг, полная трассировка версий, проверка доступов и восстановление в отдельном окружении.
