# Визуальная спецификация

Концепция: `funnel-concept.png`, создана встроенным image_gen. Текст запроса: полный экран русскоязычной «Продуктовой фермы», белая рабочая область, светло-серая боковая навигация, тёмная типографика, жёлтый акцент, воронка этапов, вкладки активных/архива, поиск, приоритет, пустое состояние без выдуманных метрик; семь представлений согласно §34.

UI остаётся нативным React/HTML. Фон рабочей области #fff; sidebar #f6f7f9; основной текст #191c25; вторичный #6c707b; border #e1e3e8; accent #f5d65c; selected #fff0bc. Семейство — системный sans-serif с поддержкой кириллицы, 14px controls, 16px body, 36px h1. Шкала spacing 4/8/12/16/24/32/40; радиусы 10/16. Outline-иконки, толщина 1.7–2px. На мобильном sidebar сворачивается, поля и действия переносятся без горизонтального скролла.

Компоненты: AppShell, Navigation, Funnel, IdeaForm, IdeaDetail, RunView, EfficiencyView, ReportView, SettingsDocs, Login; общие Button, Notice, EmptyState, Field. Главная состоит из заголовка, полосы этапов, фильтров и списка/пустого состояния. Дополнительные формы следуют той же системе.

Допустимые изменения концепции по функциональной необходимости: экран авторизации; состояния загрузки/ошибок; точное название «Критическая оценка» и отдельные стадии MVP; реальные числа активных идей и статусы интеграций. Данных демонстрационного исследования в основной интерфейс не добавлять.
