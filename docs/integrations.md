# Интеграции и стоимость

Подробный поток компонентов — в [архитектуре](architecture.md), данные — в [политике](data-policy.md). Модели и лимиты выбираются по снимку [policy.json](../web/farm/policy.json) на момент ResearchRun.

| Сервис | Данные на входе | Выход и поведение при отказе |
| --- | --- | --- |
| RouterAI / `qwen/qwen3.5-9b` | Текст идеи, ограниченный контекст этапа, JSON Schema либо поисковый запрос | Структурированный результат или текст/citations; ошибка записывается в ExecutionLog |
| RouterAI / `openai/gpt-oss-120b` | Сводка исследования, гипотез, расчёта и пробелов | Независимая критика только на `criticalAssessment` |
| RouterAI / `openai/whisper-large-v3-turbo` | Загруженный аудиофайл, язык `ru` | Текст/usage или warning; остаётся текстовый путь |
| RouterAI Web Search / Exa | Поисковый запрос основной Qwen | `url_citation` annotations; страницы ферма не открывает |
| Neon PostgreSQL | Пользовательские и системные записи | Постоянное состояние; недоступность блокирует операции с данными |
| Vercel Private Blob | Аудио, dataset, report | Приватный объект; чтение через серверную проверку владельца |
| Python Function | `calculationRunId`, внутренний токен | Читает Neon, рассчитывает и сохраняет результаты |
| HTTP Rules | Выход модели, список полей, внутренний токен | Детерминированная валидация без второго провайдера |

RouterAI использует `https://routerai.ru/api/v1` и серверный Bearer `ROUTERAI_API_KEY`. `LLMProvider.chat/research` и `SpeechProvider.transcribe` отделяют прикладной Workflow от конкретного HTTP-протокола. Автоматического переключения на другую модель нет. Повторы используют ту же модель и расходуют лимиты. RouterAI Web Search вызывается явным plugin `{id:"web",engine:"exa",max_results:3|5}`; следующий вызов Qwen без поиска формирует JSON. Описание citations и проверки фактов — в [методике](calculation.md).

## Измерение расходов

`usage.cost` от RouterAI трактуется как рубли, если оно предоставлено. До вызова система в транзакции резервирует 1 ₽ на обычную LLM, 2 ₽ на критика, 2 ₽ на обычный поиск или 3 ₽ на ключевую тему. Исследовательский лимит — 20 ₽, отдельный `mvpSpend` — 5 ₽. Без `usage.cost` резерв не списывается как нулевой: он остаётся занятым и отображается в UI. Стоимость уже отправленного запроса может превысить оценку; гарантию счёта нужно настраивать у внешнего поставщика. Распознавание речи перед созданием ResearchRun логируется отдельно от 20 ₽.

Текущая политика: ориентир 4 исследовательских раунда, предел **6** поисковых вызовов с повторами и 40 LLM-вызовов до отчёта. Отчёт v1.3 проектировал максимум 8; реализованная конфигурация строже. Ограничение аудио: 4 МиБ/5 минут; сейчас маршрут допускает до 60 попыток загрузки за час на аккаунт, но это технический rate limit, не бюджет стоимости.

Документированные ограничения RouterAI: [Web Search](https://routerai.ru/docs/guides/overview/plugins/web-search), [STT](https://routerai.ru/docs/guides/overview/multimodal/speech-to-text), [structured outputs](https://routerai.ru/pages/structured-outputs-json-claude-gpt). Цены, доступность моделей и политика хранения могут меняться; внутренние резервы — настройки продукта, не опубликованные тарифы провайдера.
