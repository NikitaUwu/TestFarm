# Интеграции v1.3

| Сервис | Отправляемые данные | Результат |
| --- | --- | --- |
| RouterAI / Qwen3.5-9B | Идея, ограниченные материалы этапа, схема ответа | Структурированный результат, usage |
| RouterAI / gpt-oss-120b | Материалы критической оценки и расчёт | Независимая критика; только criticalAssessment |
| RouterAI / Whisper Large V3 Turbo | Аудиофайл, русский язык | Текст, usage, generation ID |
| RouterAI Web Search / Exa | Поисковый запрос | Обычный текст и url_citation annotations |
| Neon | Аккаунты, версии, очередь, результаты, журналы | PostgreSQL persistence |
| Private Blob | Аудио, dataset, report | Приватные файлы через серверную проверку владельца |
| Python / Rules | ID расчёта либо поля/результат | Детерминированные вычисления и валидация |

RouterAI base URL: https://routerai.ru/api/v1. Авторизация Bearer ROUTERAI_API_KEY. Модели фиксируются в ProviderProfile: qwen/qwen3.5-9b, openai/gpt-oss-120b, openai/whisper-large-v3-turbo. Fallback отсутствует, retry использует ту же модель.

Поиск использует plugins: id=web, engine=exa, max_results=3 или 5. Следующий вызов основной модели без web plugin получает строгую JSON Schema. Источники содержат только возвращённые citations; отсутствие даты означает null, отсутствие excerpt не доказывает факт. Действия read_page нет.

## Стоимость

Предел ResearchRun — 20 ₽ по явному указанию пользователя. Политика резервирует 1 ₽ на обычный LLM-вызов, 2 ₽ на критика, 2/3 ₽ на обычный/ключевой поиск. Это консервативные настраиваемые оценки, не гарантированные тарифы RouterAI. Фактическое usage.cost в рублях заменяет резерв после ответа. Если стоимость не получена (в том числе при сетевой неопределённости), резерв остаётся занятым и отображается отдельно. Превышение доступного остатка запрещает новый вызов; уже отправленный запрос не отзывается и может стоить больше резерва. Ограничение расходов в кабинете провайдера при его наличии — отдельный внешний уровень.

Голосовой ввод до ResearchRun журналируется отдельно (не более 5 загрузок в час на аккаунт, до 4 МиБ / 5 минут). Генерация и использование MVP имеют отдельный совокупный резервный бюджет 5 ₽ на связанный run. Все счётчики и резервы сохраняются в Neon. API-ошибки не выводят необработанное тело ответа поставщика, которое может содержать секреты.

Официальные источники: [Web Search](https://routerai.ru/docs/guides/overview/plugins/web-search), [STT](https://routerai.ru/docs/guides/overview/multimodal/speech-to-text), [Structured outputs](https://routerai.ru/pages/structured-outputs-json-claude-gpt). Цены могут изменяться. Пробные платные запросы в рамках внедрения не выполнялись.
