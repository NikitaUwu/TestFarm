# Интеграции

Версия: 7, 2026-09-09. Текущая платформа — Groq Cloud Free по последнему указанию пользователя. Проверки доступны в [статусе приёмки](verification.md) и экране настроек. Временный HTTP 403 устранён изменением внешнего состояния сети; последующие живые вызовы текста, поиска и генерации успешны.

ProviderProfile v7: provider=groq, текст openai/gpt-oss-20b, речь whisper-large-v3-turbo, поиск groq/compound-mini с Groq-Model-Version: 2025-07-23 (basic search). Префикс openai в имени открытой модели не означает обращение к API OpenAI: все вызовы идут на https://api.groq.com/openai/v1. Ключ из локального GrokKey.txt записан в GROQ_API_KEY без вывода в чат. GROQ_MODEL и STT_MODEL фиксируются в снимке каждого нового запуска.

Free является тарифом аккаунта, а не отдельным ID модели. Приложение не подключает оплату и не меняет тариф; GET /models не подтверждает тариф или остаток квоты. Разрешены GPT OSS, Whisper и Compound Mini только с web_search. Произвольные tools, другие встроенные действия, service tiers и автоматическая смена провайдера запрещены. ACTIVE_PROVIDER=groq блокирует возобновление старых профилей OpenRouter/OpenAI/Ollama. Их исторические результаты сохраняются. Старые ключи не передаются работающим контейнерам.

Текст: chat/completions с JSON Schema; strict применяется к совместимым схемам, результат повторно валидируется Pydantic. Отказ, незавершённый ответ и HTTP-ошибка не считаются успехом. Выдержки источников для модели ограничены общим бюджетом 4000 символов; полученные выдержки до 16000 символов на страницу сохраняются в БД. Ограничение фиксируется в ProviderProfile. Максимум ответа исследования/программы — 4200 токенов. [Structured Outputs Groq](https://console.groq.com/docs/structured-outputs).

Речь: multipart audio/transcriptions, русский язык, JSON с исходным текстом. Локальные ограничения — 300 секунд и 20 MiB. Оригинал сохраняется в S3 до вызова; при ошибке доступен повтор без повторной загрузки. Расшифровка сохраняется отдельным артефактом. [Speech to Text](https://console.groq.com/docs/speech-to-text).

Квоты зависят от аккаунта и модели. HTTP 429 с Retry-After до 30 секунд допускает максимум два повтора; неоднозначная сетевая ошибка POST не повторяется. Длительное ограничение выводится пользователю, не вызывает платный fallback. [Лимиты Free plan](https://console.groq.com/docs/rate-limits).

При отсутствии URL Worker формирует короткий английский поисковый запрос из проблемы/аудитории, используя исходную расшифровку при пустых полях. Этот ИИ-вызов учитывается отдельно, query сохраняется до следующего вызова Compound Mini с единственным разрешённым web_search. Ссылки берутся из executed_tools/search_results либо строк URL в output базового поискового инструмента, сохраняются с исходной темой и читаются отдельно. content модели источником не становится. Compound Mini указан в лимитах Free; полный живой прогон с поиском прошёл. Версия basic закреплена после HTTP 413 у стандартной версии. [Web Search](https://console.groq.com/docs/tool-use/built-in-tools/web-search), [версионирование Compound](https://console.groq.com/docs/compound#system-versioning). Embeddings не настроены.

Для заданных вручную HTTPS-источников поиск не вызывается. URL без credentials, частных адресов и нестандартных портов; redirects автоматически не выполняются. DNS закрепляется на публичный IP на соединение. Максимум ответа 1 MiB HTML/plain text. Недоступность источника становится пробелом доказательности. Прочитанная страница сама по себе не подтверждает утверждения модели.

Rules service v1.1.0: отдельный HTTP-компонент /health, /metadata, /run. Проверяет категорию/ручную проверку/длину текста либо схему полей результата MVP. Длительность, вход и выход сохраняются. Семантическая правильность оценивается отдельно по expected_label или критериям MVP.

Runner v2: X-Runner-Token, классификационная цепочка и типизированные генерируемые программы QuickJS, отдельный процесс на запрос, /cancel и /purge. Постоянная идемпотентность в runner_state; исход прерванного запроса не угадывается. Нет DB/S3 credentials, выход только через CONNECT api.groq.com:443. MinIO хранит объекты в objects, PostgreSQL 15 — бизнес-данные в pgdata. Web не получает ключ провайдера.

Сохранён необязательный локальный модуль faster-whisper; модель base подготовлена в speech_models. Он не является текущим STT и не вызывается автоматически вместо Groq. История смены платформ — в [журнале](development-log.md), передаваемые данные и хранение — в [политике данных](data-policy.md).
