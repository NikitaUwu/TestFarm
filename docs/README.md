# Документация проекта

Актуальное описание исходников `main` по состоянию на 22 сентября 2026 года. Начните с [контекста](context.md) и [руководства пользователя](user-guide.md). Команды и пределы сверяйте с текущим `web/farm/policy.json`, поскольку каждый ResearchRun сохраняет собственный снимок конфигурации.

| Для кого | Документ | Содержание |
| --- | --- | --- |
| Пользователь | [Руководство](user-guide.md) | Идея, голос, очередь, отчёт, решение и MVP |
| Разработчик | [Архитектура](architecture.md) | Компоненты, границы доверия и выполнение |
| Разработчик | [Модель данных](data-model.md) | Таблицы, связи, версии и происхождение выводов |
| Разработчик | [Контракт API](api.md) | Маршруты, доступ, запросы и ошибки |
| Аналитик | [Исследование и расчёт](calculation.md) | Источники, прогоны, формулы, неопределённость |
| Оператор | [Развёртывание](serverless-deployment.md) | Локальная подготовка, миграции, Vercel |
| Оператор | [Эксплуатация](operations.md) | Журналы, восстановление, конфигурация |
| Все | [Данные и безопасность](data-policy.md) | Передача, хранение, доступ, удаление |
| Все | [Интеграции](integrations.md) | Внешние и внутренние сервисы, стоимость |
| Ревьюер | [Требования](requirements.md) | Прослеживаемость требований к коду и ограничения |
| Ревьюер | [Статус проверки](verification.md) | Что известно, что не проверялось, критерии приёмки |

Источники решений: [отчёт v1.3](target-report-v1.3.md), [изменения v1.3](release-v1.3.md), [постоянные инструкции](../AGENTS.md). `target-report-v1.2.md`, `serverless-progress.md`, `vercel.md` и ранние записи [журнала](development-log.md) сохранены как исторические материалы: команды из них могут относиться к удалённому Docker/backend-контуру. Браузерная страница `/docs` — краткая справка для пользователя; документы этого каталога описывают проект подробнее.
