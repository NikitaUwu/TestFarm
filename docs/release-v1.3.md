## Очистка

Удалены отслеживаемые исходники прежнего backend, Docker Compose, старые конфигурации и скрипты, неиспользуемые экраны и инструменты импорта исторических данных. Они восстановимы из Git. Исторические документы помечены; локальные секреты, QA-данные и Docker volumes не затрагиваются. Рекурсивное удаление кэшей отклонено автоматической проверкой разрешений; кэши сохранены вне Git. Исходники удалены отдельными ревьюируемыми патчами.

## Состояние

Сделано локально: AI-адаптер, двухшаговый поиск, citations, независимый критик, учёт стоимости, UI и документация. Исходники отправлены в GitHub; ROUTERAI_API_KEY и необходимые серверные переменные сохранены в Vercel. Production публикуется из связанного проекта; итоговый READY и адрес фиксируются в ExecutionLog отдельным событием публикации. Обязательная облачная сборка — часть deployment. Отдельные тесты/контрольные прогоны не запускались.
