# Развёртывание по отчёту v1.2

Целевой проект Vercel имеет Root Directory `web`. Frontend, API Route Handlers, Vercel Workflow, HTTP-компонент Rules и Python Function находятся в одном deployment. `API_URL`, Cloudflare Tunnel, постоянный Worker и запущенный ноутбук ему не нужны.

## Переменные

В настройках Vercel добавьте серверные переменные для нужных окружений:

| Переменная | Назначение |
| --- | --- |
| `NEON_BASE` или `DATABASE_URL` | Строка подключения Neon. При наличии обеих используется NEON_BASE |
| `BLOB_READ_WRITE_TOKEN` | Доступ к Private Blob |
| `TSARROUTER_API_KEY` | Ключ Царь Роутера |
| `TAVILY_API_KEY` | Ключ Tavily |
| `INTERNAL_API_TOKEN` | Случайный общий секрет внутренних вызовов Python и Rules |
| `APP_ORIGIN` | Полный адрес этого приложения, например https://имя.vercel.app |

Не используйте префикс NEXT_PUBLIC для секретов. Локальный `web/.env.local` не отправляется в Git и сам по себе не задаёт переменные Vercel. В защищённом preview для внутренних вызовов предусмотрен VERCEL_AUTOMATION_BYPASS_SECRET.

## Подготовка

Из каталога `web`: установка `npx --yes pnpm@10.34.5 install --frozen-lockfile`, затем `npx --yes pnpm@10.34.5 run db:migrate`. Миграции создают таблицы с префиксом farm_ и не заменяют исторические таблицы. В текущем окружении первая миграция уже применена к предоставленному Neon.

Vercel: Framework Next.js, Node 22.x, Output Directory оставить без переопределения. Команды установки/сборки заданы в web/vercel.json. Python Function находится в web/api/calculate.py; зависимости — web/requirements.txt. Workflow подключён через withWorkflow.

## Исторические данные

**Не входят в текущий объём:** 11 сентября пользователь отменил перенос. Новый контур использует новую регистрацию; старые данные не удаляются. Команды ниже сохранены только как необязательные инструменты и при публикации не запускаются.

Для однократного переноса задайте LEGACY_DATABASE_URL только локально, затем выполните `npx --yes pnpm@10.34.5 run db:import-legacy` из web. Источник читается в транзакции READ ONLY. Сохраняются ID аккаунтов, scrypt-хеши паролей, идеи и версии; исторические результаты сохраняются отдельным архивом с исходными связями. Конфликт логинов отменяет транзакцию. Старые процессы не возобновляются автоматически в новой архитектуре.

Если источник находится в прежнем Docker Compose без открытого порта PostgreSQL, команда `db:export-legacy` сохраняет согласованный снимок в игнорируемом Git файле `.local/legacy-export.json`. Затем `db:import-legacy` использует этот снимок, если LEGACY_DATABASE_URL не задан. Снимок содержит хеши паролей; не публикуйте его.

Команда `db:import-legacy-files` переносит связанные файлы из старого S3 в Private Blob и сохраняет ID артефактов. Источник читается через старый API-контейнер. Старое хранилище нельзя удалять до завершения переноса. Существующие cookies не переносятся: пользователь входит с прежним паролем.

## Политика интеграций

Царь Роутер получает содержимое идеи и ограниченные результаты исследования. Канал Qwen выбирается из конфигурации, цена проверяется перед запросом; платные fallback запрещены. Распознавание речи блокируется, если бесплатный маршрут Whisper нельзя однозначно закрепить. Текстовый ввод остаётся доступен; недоступность STT не означает готовность голосового сценария.

Tavily получает поисковые запросы и публичные URL. Полные ключи и строки подключения не передаются модели. Выполнение инструментов ограничивается сервером. Неизвестный baseline, ручная проверка и качество не заменяются нулями. Синтетические данные не дают измеренного доказательства эффективности.

## Состояние готовности
