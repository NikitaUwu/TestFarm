# Данные, доступ и безопасность

Документ описывает наблюдаемое поведение кода, а не юридическую гарантию хранения у Vercel, Neon или RouterAI. Внешние сроки и условия следует проверять в кабинетах соответствующих сервисов. [Модель данных](data-model.md) перечисляет активные таблицы, [API](api.md) — серверные границы доступа.

## Какие данные куда попадают

| Получатель | Данные | Для чего |
| --- | --- | --- |
| Neon PostgreSQL | Аккаунт, солёный scrypt-хеш пароля, хеш сессионного токена, идеи/версии, очереди, цитаты, прогоны, отчёты, решения, журналы вызовов и JSON входа/выхода | Постоянное бизнес-состояние и восстановление Workflow |
| Vercel Private Blob | Загруженное аудио, JSON-артефакты dataset/report | Приватное файловое хранение |
| RouterAI: Qwen | Текст идеи, ограниченные результаты предыдущих этапов, схема JSON, отдельные входы эксперимента и MVP | Анализ, варианты и выполнение |
| RouterAI: Web Search/Exa | Поисковый запрос | Источники и citation annotations |
| RouterAI: Whisper | Аудиофайл, имя файла, код языка `ru` | Распознавание речи |
| RouterAI: gpt-oss-120b | Компактное содержание идеи, подтверждённые claims, гипотезы и расчёт | Независимая критика |
| Браузер | Cookie сессии; пилотные наблюдения в `localStorage` | Вход и локальный экран мониторинга |

Приложение не запрашивает полные страницы источников. Записанные пользовательские тексты и возвращённые веб-фрагменты считаются недоверенными входами для модели. RouterAI и инфраструктура поиска имеют собственные правила обработки данных; удаление объекта в ферме не означает удаление данных или технических журналов поставщика.

## Доступ

Пароли хешируются scrypt со случайной солью 16 байт (`N=32768`, `r=8`, `p=3`). Cookie сессии `HttpOnly`, `SameSite=Strict`, `Secure` в Vercel; БД хранит SHA-256 токена, срок сессии — 7 дней. Серверный `actor()` и запросы по owner ID защищают личные идеи. Мутации дополнительно требуют `X-Farm-Request: 1` и проверяют Origin, когда он предоставлен. Rate limits сохраняются в Neon. Секреты находятся только в серверном окружении; `.env.local` и `routerai.txt` исключены из Git.

Публичная ссылка содержит случайный токен и открывает **полный сохранённый `report.content`**, а не отдельно очищенную проекцию. Он может включать формулировку и исходный текст идеи, источники, конфигурацию и выводы. Аудиофайл по публичной ссылке не выдаётся, но перед публикацией нужно считать весь JSON отчёта потенциально доступным получателю. Отзыв ссылки удаляет токен из активного отчёта, но не стирает сделанные получателем копии.

MvpSpec ограничен полями `string/number/boolean`, промптом и флагом Rules. Сервер валидирует вход/выход; динамический JavaScript, `eval` и произвольный HTTP из спецификации не исполняются. Записи в сторонние бизнес-системы MVP не делает.

## Ограничения входов и хранения

Идея: максимум 20 000 символов текста, название — 180 символов. Аудио: максимум 4 МиБ и по результату STT не более 300 секунд; сервер принимает WebM, WAV, MP4/M4A, MPEG/MP3, OGG и AAC при разрешённом MIME/расширении. Размер ограничен до сохранения, длительность — после ответа STT, поэтому уже отправленный длинный файл может быть тарифицирован. В течение часа допускается 60 POST-запросов на `/api/audio` на аккаунт; отдельный общий лимит мутаций — 100 за 10 минут. Поиск и LLM ограничены BudgetPolicy, размером контекста, ответов и таймаутами.

Автоматический срок удаления идей, аудио, logs и `localStorage` сейчас не установлен. При удалении идеи API сначала проверяет отсутствие активной задачи, затем удаляет привязанные Blob-файлы и связанные строки из активной БД. Аудио, сохранённое до привязки к идее, может остаться осиротевшим; отдельного фонового уборщика в коде нет. Пилотные наблюдения в `localStorage` не удаляются серверным DELETE и остаются на этом устройстве до очистки браузера. Резервные копии Neon/Blob имеют независимые сроки, которые нужно настраивать у провайдеров. Это открытые ограничения политики удаления, а не обещание полного стирания.

ExecutionLog и `farm_action_data` хранят ввод и вывод некоторых действий, поэтому доступ к Neon и резервным копиям должен считаться доступом к пользовательским данным. Текст ошибки внешнего сервиса частично выводится после маскирования строк формата ключа; нельзя считать эту маскировку полноценной очисткой любых возможных секретов, которые мог вернуть поставщик. Не помещайте ключи в текст идеи или файл аудио.
