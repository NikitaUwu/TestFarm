# Контекст и границы

Версия документа: 1, 2026-09-08.

Ферма помогает пользователю снизить неопределённость продуктовой или внутренней ИИ-гипотезы и раньше остановить слабый вариант. По запросу от 2026-09-10 вместо выбора Owner/Reviewer введены самостоятельная регистрация и вход по логину или почте и паролю. Личные пространства изолированы; прежние аккаунты и данные сохранены. Публичный посетитель читает явно опубликованную проекцию отчёта. Командные пространства не добавлены.

Пользователь фермы заводит идею, управляет проверкой и принимает решение. Аудитория самой идеи описывается отдельно в карточке и исследовании. Синтетические персоны не являются интервью или подтверждением спроса.

Термины: IdeaVersion — неизменяемый вход; ResearchRun — исследование конкретного входа; StepRun — проверенный результат шага; TaskObservation — один фактический прогон; CalculationRun — версия программного расчёта; stale — результат прежних входов; MVP — один завершённый сценарий после решения человека.

Исходник — МастерПромпт.md. Постоянными инструкциями владеет корневой AGENTS.md, повторяемыми процедурами — четыре project-local skills. Их карта находится в [реестре](requirements.md).

Принятые локальные решения: предел аудио 20 MiB; первый поддержанный шаблон MVP — классификация обращения с независимым сервисом правил; экспериментальные варианты отличаются промптом. Автоматическая генерация произвольного продукта этим шаблоном не покрывается. Следующие типы MVP требуют реализации и отдельной приёмки.

UI построен по локальной концепции в `docs/design/funnel-concept.png`: светлая поверхность, тёплый жёлтый акцент, компактная навигация, предметные экраны. Брендбук не предоставлен.

Состав решения и ограничения: [архитектура](architecture.md), [проверки](verification.md).
